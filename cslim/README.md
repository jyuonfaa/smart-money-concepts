## 🚀 How to Sync a New Antigravity Instance

### Step 1: Run the System Bootstrapper
On your new device, open a terminal in the project root and execute the bootstrapper script:
```bash
python cslim/bootstrap.py
```
**What this does automatically:**
1.  **Dependencies Audit:** Verifies that core libraries (`pandas`, `numpy`, `plotly`, `pytz`) are correctly installed.
2.  **Knowledge Base Replication:** Copies all workspace-localized Knowledge Items from `cslim/kis/` directly into your active device's system directory: `C:\\Users\\<USER>\\.gemini\\antigravity\\knowledge\\`.
3.  **Regression Validation:** Executes the full regression suite (`verify_step2.py`, `verify_video8.py`, `verify_month2_video2.py`) to confirm zero regressions exist in active indicators.

### Step 2: Inject Workspace Memory
To instantly align the new Antigravity instance with the complete repository context, copy the fully-baked initialization prompt from:
👉 **[cslim/antigravity_prompt.txt](file:///d:/C.Slim/ict-intelligence/cslim/antigravity_prompt.txt)**

Paste this prompt directly into your very first message to the fresh model!
